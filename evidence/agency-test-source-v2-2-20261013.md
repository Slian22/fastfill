**F01 — Combined-loss backward does not prove each geometry regularizer is differentiable** (medium). [test_execution.py:36-49](/Users/slian/Desktop/3D/Worldedge/OptiScene/fastfill/v2/tests/test_execution.py:36).

The test checks collision, boundary and box values are positive, then backpropagates only result['loss'] and requires finite position gradients. **Undetected result:** A detached positive constant for one or all optional regularizers can satisfy these assertions while another active loss supplies the position gradient. **Claim affected:** This case cannot substantiate that each optional geometry penalty contributes a useful training gradient. **Suggested oracle:** Use separate nondegenerate fixtures with other loss terms disabled; differentiate each regularizer and require finite nonzero gradients with an analytically expected direction.
