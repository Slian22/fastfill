# 创新性与下一轮研究策略（2026-10-15）

状态：研究建议，非已锁定实验协议。基于截至本轮可见的结果、原始论文和三类专家审查；本轮没有启动新训练、渲染或付费评测。下面的时间与规模是工作量估计，不是完成承诺或统计功效计算。

## 1. 判断

当前有价值的是未知家具尺寸的实际任务、多来源审计和受控比较，以及已经可运行的系统。方法创新尚未由现有结果确立。SFT/DPO、视觉 critic、局部修复、验证后回滚、大小模型切换分别都有近邻；把它们拼起来不自动形成强研究贡献。

本轮三代理复核后的最终建议是优先探索：**未知尺寸、仅有家具类别的条件下，布局反馈能否帮助选择合理尺寸，并在训练未见的家具组合上胜过“多尺寸采样＋每组完整重规划”？** 创新候选是反馈如何利用尺寸与布局的相互影响，而不是联合输出size/pose或普通交替优化；其独立新颖性和实际增益都尚待证明。

固定估计尺寸的修复作为低成本先导诊断：残留失败有多少来自朝向受限、逐步单调验收和搜索邻域选择？当前S1已经包含双对象联合平移，不能把它描述为纯单对象基线。若普通搜索已解释收益，就不为“联合修复”另训模型。质量—成本路由保留为工程基线，026已有简单规则证据。三条路线共同依赖可信评价；以下A/B保留详细对照，最终研究排序见第8节。

## 3. 相关工作边界

| 已有工作 | 公开机制及对我们的限制 |
|---|---|
| [OptiScene](https://arxiv.org/abs/2506.07570) | 给定资产尺寸的布局生成、SFT和多阶段DPO已有先例。 |
| [SceneSmith](https://arxiv.org/abs/2602.09153) | designer/critic/orchestrator协作已公开；加视觉critic本身不足为新贡献。 |
| [LayoutVLM](https://arxiv.org/abs/2412.02193) | 语义关系与几何目标联合优化已有先例；应列为相关方法和可适配基线。 |
| [Roomer](https://arxiv.org/html/2608.01973v1) | 对象归因、局部补丁、确定性搜索、全场验证、关系保护、修复训练及自适应停止均已公开。标准循环一次修改一个目标；附录G允许缩放、增删及替换，另有整场修改消融。附录F的硬保护集合限于依赖对象全部未被编辑的已满足关系。 |
| [ScenePilot](https://arxiv.org/html/2608.30307v1) | 分组生长、动作列表、局部搜索及修复轨迹训练已有先例。局部范围含新功能组及邻近锚点/支撑物，动作允许缩放；修复阶段本身不负责增删。不能简化为纯单对象修复，也不能把动作列表直接等同于显式联合求解。 |
| [Function2Scene](https://arxiv.org/abs/2605.30819) | 从功能需求生成17类约束，并进行工具辅助的检查与修复；“关注功能而不只关注碰撞”本身已有直接先例。 |
| [RoomCraft](https://arxiv.org/abs/2506.22291) | 关系网络、约束驱动调整与冲突感知定位已有先例；不能以“建图后消解冲突”概括新贡献。 |
| [DiffuScene](https://arxiv.org/abs/2303.14207) | 生成的位置、尺寸、朝向等属性已有联合表示；“把尺寸从输入变成输出”相对OptiScene改变了任务，但不是整个领域首次联合预测。 |

另外，[RouteLLM](https://arxiv.org/abs/2406.18665)已研究大小模型质量—成本路由；[风险感知自修正研究](https://arxiv.org/abs/2609.35832)已研究何时修改及修改造成的损害；[神经大邻域搜索](https://arxiv.org/abs/2107.10201)已学习选择重新优化的变量集合。因此，“会选择物体”或“会决定是否调用大模型”也不是充分的新颖性证明。

以上是针对当前方案的近邻核验，不是穷尽检索；不据此声称任何“首次”。跨论文表格因输入、动作自由度及评估器不同，不能直接比较分数。

## 4. 候选A：保持关系的联合修复（先导诊断，非已确立主创新）

### 可证伪假设

一部分固定家具清单的场景存在耦合冲突：逐个修改物体/支撑子树时，中间状态可能变差；结构化选择少数对象进行优化，可能在相同预算下比普通搜索更有效。这里检验的是有限预算下的求解效率与损害控制，不是声称联合编辑具有串行编辑无法表达的静态终态。

本轮直接核验 [S1源码](../../../fastfill/comparison/output_repair.py)：仅允许XY平移，冻结yaw、z与parent；每一步要求所有审计分量不升，已尝试将冲突双方各推开一半（文件第18–39行）。此外，51+物体不自动等于空间拥挤：诊断须区分房间面积、地面根物体占地密度、支撑深度和来源。

先把它称为“给定动作集合和预算下停滞”，不能根据求解器失败宣称数学不可行或已证明死锁。

### 最小方法定义

1. 用可观测场景状态构图，区分碰撞/边界/门通道约束、真实支撑、显式功能需求；初始布局推断的关系只是带置信度的软约束。
2. 选择少量允许共同移动的支撑单元，例如2–4个；联合优化平移和必要的朝向，其余状态固定。
3. 提交整个编辑后的布局时验证硬约束和受保护关系。内部优化候选可以暂时不合法，不代表允许实际执行碰撞运动。静态布局可解与真实机器人搬运可行是两个任务。
4. 仅在廉价诊断显示空间后，训练小模型预测修改集合、可获得的收益和计算开销。监督来自同一状态上实际执行的候选干预，保留失败与有害编辑，不仅收集成功样本。

物体集合、类别、尺寸及支撑父子身份冻结。旋转支撑单元必须正确变换其子对象。保护关系来自输入需求或经核验的有效关系，推理不读取隐藏GT关系；也不能把初始错误关系永远冻结。

### 最便宜的否证实验

先在开发房间上冻结初态、尺寸及家具清单，做以下机制对照；全部为计划，尚无新增实测。

| 对照 | 改变的因素 | 用途 |
|---|---|---|
| 当前S1 | 原XY动作，包含双对象半量平移；分量单调 | 忠实基线 |
| S1候选＋非单调搜索 | 保持候选动作，允许内部状态暂时变差；终态验收 | 排除验收规则解释 |
| XY＋yaw × 单调／非单调 | 增加朝向动作，保持其余预算及终态规则 | 与前两行组成2×2自由度消融 |
| 随机／几何近邻／结构选集 | 相同组大小、动作范围、内部优化器与终态规则；另加同选集非单调串行更新和全局优化 | 判断结构选集及联合求解是否有独立贡献 |
| 通过诊断后才学习选集 | 对比最强非学习方法及通用神经邻域选集 | 判断学习和场景特定结构是否必要 |

另以适配后的Roomer式修复作为相关方法基线。分别报告等时间和等验证预算，选集、内部候选、重启和失败都计入成本；给简单方法增加预算，绘制收益曲线。

若联合动作不增加可验证修复率，耦合假设缺少支持；若近邻或随机集合已同样有效，就保留简单算法，不声称学习模块必要；若非单调串行搜索已经解释全部收益，不声称联合集合是关键机制。若收益只来自更多候选、缩小物体或破坏功能关系，则否证目标贡献。精确“最小集合”只有穷举/证书足够时才成立，通常应写“稀疏集合”。有学习阶段时，应加入通用神经邻域选择、去掉支撑/功能关系特征的选集器，检验场景特定设计是否必要。

## 5. 候选B：预测干预收益，分配计算

当前022按checker失败触发升级。要检验的是：**相同预算下，预测不同干预的实际收益，是否优于按失败数或物体数分配计算？**

本轮补读的[026报告](results/frontier-026/report.md)已有A/B离线分析，不能再把026整体记为未完成。固定尺寸的300房pilot中，ESC-STRICT严格准入为.753、调用比例.557；BIG为.723、调用比例1.000。简单规则已有竞争力，因此学习router的必要性尚未建立。这里是已曝光pilot上的离线两候选择优，BIG行没有同样的本地候选；L的token按全运行均值摊分。不能据此认定新路由器有效、真实费用节省同等比例或同质量更快。正式比较须给BIG同样的选择器/重采样机会，按完整预算画前沿。

从同一开发状态分别执行S1、联合修复、critic修复或重新生成，记录质量变化、关系损害、成本及失败。模型估计“状态×动作”的增量效果，不只估计房间困难程度。最初只做两种干预，用浅模型和房屋组交叉验证；不先做复杂RL。

重要对照是随机升级、失败触发、困难度排序、固定最佳策略、全程BIG，以及不经过本地微调模型的BIG+同样工具。全部策略共享候选动作、调用上限、反馈与后处理。另比较未微调同底座+S1，以检验放置器训练是否必要。

开发数据要包含checker已通过的房间，因为其中也可能有真实功能缺陷。只观察022升级房间会造成选择偏差。026已有独立大模型答案只能支持离线替换分析，不能冒充“看到局部布局后修复”的反事实效果。

先计算一个诊断上界：事后知道每种动作结果时，选择器能比最强固定策略改善多少。这个oracle不计作可部署结果。如果上界很小，或交叉验证的收益排序不优于简单规则，就停止路由方法扩张。

## 6. 测量与确认性证据

### 保持任务原意

原任务仍是“房间信息+家具描述→尺寸、位置、朝向”。估计后冻结尺寸是隔离摆放能力的受控实验，不是宣称尺寸已知或正确。端到端结果与共同尺寸实验分别报告；未知尺寸阶段的真实性、偏差及合理多样性不能被固定尺寸实验取代。

实现范围还需说清：[contract.messages](../../../fastfill/comparison/contract.py)第213–243行的可移动对象输入只有id/category，placement臂另加估计尺寸；当前比较没有丰富的家具描述或显式功能任务。只有“chair”不能唯一决定真实尺寸，GT尺寸MAE是参考误差，不是所有合理生成解的正确性判定。功能要求若新增到输入，属于新任务版本，须给全部基线相同信息。输出里预测的支撑关系也可能错误，不能冒充输入事实。

### 独立验证

保留历史checker与strict指标。新研究如采用功能主终点，应先验证其含义并单独锁定协议，不能为改善排名而修改旧分数。

几何验证应考虑朝向、高度、支撑与合理收纳，资产充分的子集用mesh复核。任务通过使用预先指定对象与操作空间，例如入口到目标的可达性、门开启区域、目标物品的可操作空间；不把每件装饰品一律视为必须可达。简单导航/交互测试与人工盲评用于检验规则是否测到了真实使用，GPT评分只作辅助。

人工验证先覆盖检测器分歧案例，区分真缺陷和误判；正式总体估计另用随机/分层抽样并保留抽样权重。两个GPT型号或隐藏方法名，不足以完全排除critic/judge共享偏好。

### 数据隔离与统计

旧test已参与后续方案设计，025/026是探索性。从旧test重新按房型抽300间不能恢复独立确认。新方法须在全新房屋连通组、或确实未曝光的预留集上确认，并跨来源去重；任何新切分都先核验与训练数据重合。

确认时冻结模型、阈值、尺寸策略、动作预算与评估程序。使用房屋组配对bootstrap；总体分布加权与房型等权分报。小房型只有约20间时区间很宽，不能声称逐房型胜出。样本量依据pilot的配对差异、组内相关与目标精度估算。

学习策略只用部署时可见信息。报告失败、超时、无资产以及原始合法布局被破坏的比例；拒绝输出不能通过排除分母抬高成功率。任务不可行性分为“有可行见证／有不可行证明／未知”，预算耗尽属于未知。

## 7. 推荐次序与停止条件

1. **约半天至1天：**复用现有审计，检查60–100个开发案例的规则分歧及拥挤失败，确定可信目标与主要失败结构。这是诊断集，不是总体统计证明。
2. **约1–3天：**先分离yaw与单调限制，再对尺寸冻结、多尺寸完整重规划、反馈选尺寸三个非学习方法作等预算小试验。复用026已有A/B分析，继续区分其尚缺的C范围及实际完整成本证据。
3. **只有小试验通过才投入约3–7个工程日：**收集训练侧干预数据、训练小型选集或收益预测器。一次只推进更有证据的一条机制，不同时扩张两个大模型训练路线。
4. **正式论文验证另计约2–3人周：**独立房屋组、强基线、完整成本和人工校准。先规划300–450房，最终规模依据pilot计算；现阶段不宣称功效足够。

025继续作为critic组件实验，026继续作为成本证据；现有27B作为可复用初始化器。若去掉27B微调后质量—成本不下降，就应接受其非必要性，采用更简单系统。

候选“尺寸不确定性下的稳健修复”暂列后续：只有引入不可任意缩放的真实资产目录、标注误差或可测量的尺寸随机性时，才有清晰部署意义。当前RoomGen缩放资产适配bbox，不能凭空假设尺寸匹配失败。该方向还需与安全余量、普通采样及稳健优化比较，不作为本轮马上重训的理由。

论文可形成的三个贡献层次是：经独立验证的任务/评估问题；确有增益的场景特定修复机制；与强直接大模型比较的完整质量—成本证据。任何一层未被实验支持，就收窄论文主张，而不是用更多组件替代证据。

## 8. 本轮专家分歧与研究取舍

本轮使用Research Synthesist、AI Engineer与Statistician三个独立子代理。原文复核与工程视角都更倾向“尺寸—姿态协调及未见组合泛化”，并建议撤下通用联合修复作为主创新；统计视角要求先排除动作自由度、验收方式与更多算力。最终采用这个研究排序，但不把专家判断当作方法有效或新颖的证据。

**科研优先：**从训练侧类别分布取得保留长宽高相关性的少量尺寸候选，比较“一次选尺寸后摆放”“多尺寸方案分别完整重规划”“利用布局反馈交替选择尺寸与姿态”。三者共享尺寸候选、动作自由度、求解器和预算；增加相同总占地而改变对象间尺寸分配的控制，还检查长宽比、高度及类别合理尺度。若多尺寸采样加重规划已同样有效，或收益只来自整体变小，就不训练复杂耦合模型。只有确认未见组合未进入训练，并控制类别频率、物体数、来源及密度，才能讨论组合泛化。普通联合预测和交替优化都不能直接声称新颖。

**单模型实现候选：**保留27B初始化器，从同一初态执行不同候选干预，记录几何收益、关系损害、尺度变化、成本与失败。只有发现稳定可学的反馈收益后，才让同一个模型学习输出稀疏尺寸选择/姿态编辑；正式系统仍由独立几何检查器验收。这是待验证的实施选择，修复轨迹训练本身不构成新贡献。固定尺寸的结构选集是一个必须检验的组件，而非预先决定必需的模块。当前输入没有功能任务，不能据此声称功能任务满足。

无论选择哪条路线，都比较未微调同底座、微调模型与简单初始化器＋相同后处理。若微调没有独立质量—成本收益，就接受它不是必要组件。现有交付工程与新科研验证分别记录；本轮仅更新研究建议，没有启动新训练或评测。
