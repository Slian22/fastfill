# 自动研究流程参考与本轮执行

用户于2026-10-13指定参考 [ARIS](https://github.com/wanshuiyin/auto-claude-code-research-in-sleep) 和 [Karpathy autoresearch](https://github.com/karpathy/autoresearch)。已阅读两者官方仓库说明。采用固定评测与预算、先小规模实际验证、独立审核、运行日志及状态文件、失败保留这些原则。ARIS 的执行／评审循环适用于本项目；Karpathy 的5分钟语言模型验证指标只是其示例，不能替代场景几何和视觉评测。

本轮主端点保持配对SFT J0/P0。训练集用于拟合，验证集用于长度与容量设计，历史test用于冻结后的最终测量。不会根据test指标反复改模型、解析器或样本选择来追求更高分。

已通过独立Agency复核并修复：数据连通组闭包、OOF先验、固定尺寸目标修复、配对自举、真实资产映射、结果与输入身份绑定、GPT评分分母。长序列新增验证覆盖两臂共同上下文预算、超长请求保留、EOS与预算截止区分及篡改回执拒绝。

运行方式遵循用户服务器手册的Slurm依赖与每作业24小时上限；Agent留在本地，计算和API批处理使用有界Slurm作业，不在登录节点常驻Agent。阶段间状态写入本地文档和不可覆盖的运行目录。自动流程遇到未覆盖的错误时保存失败证据，绝不将部分结果标记为完整。

目前不声称存在永久后台智能代理：持久运行的是已审核的有界脚本。模型训练／推理由服务器独立继续；本地真实资产渲染依赖Mac持续可用。
