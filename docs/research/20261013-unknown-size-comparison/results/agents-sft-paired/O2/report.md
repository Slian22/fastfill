# 未知尺寸：LLM 代理 L 与 J／P 同输入对比

L 收到与 J 完全相同的 system 与 user 消息，另加一条对所有请求相同的“只输出 JSON”后缀，由 J 的解析器判定。L-raw 是第一次回答；L-harness 是至多两轮修复后的答案，修复消息只含解析器错误文本。P 的尺寸来自训练集先验，不是预测。
