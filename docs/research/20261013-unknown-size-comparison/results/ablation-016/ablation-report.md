# 修订 016 §3：DPO2 归因消融（dev，单次贪心，无修复；探索性）

dev-select-v1 的 600 个房间，HF 精确策略（训练基座 + 未合并的 FP32 adapter），与修订 010/013 相同的共享推理计划。所有候选均从 rpo-dpo1 的精确策略出发；(b)(c)(d) 的优化器步数相同（S = 2248，2 个 epoch，有效批量 4）。(b) RFT 与 (d) op-dpo2 各训练两个种子（42、43，逐种子报告并给出两种子均值）；(a) rpo-dpo1 与 (c) pert-DPO2 为单种子。测试集不受此消融影响。

种子的作用：train_dpo --seed 设定 transformers.set_seed（LoRA dropout 掩码等随机数）与 DistributedSampler 的每 epoch 数据顺序；所有候选的 LoRA 都以 rpo-dpo1 的 adapter 为初值（--init_adapter），初始权重不随种子变化，因此附录 C8 所说的“LoRA 初始化”在本设置下不起作用。N 不是 4 的倍数时，DistributedSampler 每个 epoch 用打乱后序列开头的 ≤3 行重复样本补齐，这几行也随种子变化，所以两个种子每个 epoch 实际训练的样本多重集可以差这几行（(b)(d) 的 N = 4496，每 epoch 补齐 0 行；(c) 每 epoch 行数是 4 的倍数，不补齐）。训练文件、步数、初始 adapter、训练基座与参考策略在两个种子间相同。

说明：
- “≈”按预先约定操作化为 a′ 与下游接受率两项差异的 95% CI 均包含 0；这不是等价检验，600 个房间上成功率差异的标准误约 0.012（CI 半宽约 0.025）。CI 端点超出修订 013 的 ±0.01 采纳门槛时，“≈”只表示未分辨出差异，不表示差异小于该门槛。
- 足迹偏差 B：P 的尺寸取自请求中的训练先验（placement 合同无尺寸字段），因此每个候选的 B 是训练先验在该候选完整房间上的偏差，不是模型选择的尺寸；各候选 B 与尺寸 log MAE 的差别只来自完整房间集合不同。
- (b) 的训练行即 op-dpo2 所训的 pair 文件原样（同样的行、行序与重复次数），--sft_only 不读取 rejected。同种子下 DistributedSampler 的数据顺序相同；损失只差 DPO 项，但 LoRA dropout 掩码的随机数流不同（DPO 路径每批多一次策略前向），所以同种子的 (b) 与 (d) 不只差 DPO 项。(c) 的 chosen 是 GT，rejected 是合成扰动。
- 两种子均值是两个种子数值的算术平均，只作报告；解读只看逐种子的配对 CI。(a)(c) 为单种子，涉及它们的 CI 不反映训练种子带来的波动。
- 分层表为描述性（修订 016 §5），房间数少的分层波动大。
- 本消融为探索性分析，不改变修订 005–015 的任何结果或决定。
