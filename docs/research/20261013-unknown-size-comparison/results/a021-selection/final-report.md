## 决定：交付 021 臂（A，27B）（vLLM 贪心（BF16 LoRA））

确认通过：测试集上只运行该模型与同引擎的 R 各一次。

规则（修订 021 §4，预注册）：在 dev-select 的 600 间上，每个候选用 §3 的引擎；护栏相对同引擎的 R（含边界）：完整率 ≥ R − 0.005，OOR ≤ R + 0.01，严格准入 ≥ R − 0.01，GT 关系保持率 ≥ R − 0.03，21 个及以上物体房间的检查器成功率 ≥ R − 0.02（某值只在一方缺失则不满足，两方都缺失视为无可度量而满足）。R 与通过护栏的候选中取原始冻结检查器成功率（全部请求，未完成算失败）最高者；在 max(0.01, R 的 vLLM 两次运行差) 的平局带内取更便宜的模型（8B 先于 27B），再 R，再更高的检查器成功率，再候选顺序。胜者不是 R 时，须在 3,000 间确认切片上（同引擎）胜者 − R 的房屋连通组配对 bootstrap 95% CI 下界 > 0 才交付，否则 R 保持交付。

GT 关系保持率：GT 上成立的 on 与 against_wall 关系（build.extract_constraints 的确定性候选，排除扁平与低于 5 cm 的物体）在预测布局上仍成立的比例（validate.holds）；修订只写了 validate.holds，关系集合为本工具的读法。
