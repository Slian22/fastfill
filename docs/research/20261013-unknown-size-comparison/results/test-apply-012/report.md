本报告是修订 012 §4 在测试集上的一次性应用，属次要、探索性（EXPLORATORY）结果；修订 005–011 的确认性结果与交付结果都不变。dev 决定（decision-012）：S1 采纳，S2（最佳 N 选一）不采纳；因此测试集上只应用 S1，设定同 dev（max_trials 2000，time_limit 60 s），不做最佳 N 选一。

完整率；检查器成功 = geometry_success（冻结检查器）；下游接受 = downstream.accept（EmbodiedGen path A 严格规则的移植，每个门入口）；两者都过 = 同时满足。比率分母为该范围的全部请求，未完成输出计为失败。

B = 足迹尺寸偏差：该系统自身的完整房间上（n = levels.csv 的 complete_rooms）每个房间 log(预测 / GT 的 x·y 面积) 的均值，再对房间平均。房间集合不同于 report-v2 的 T1_bias（J 与 P 都完整）与 T5（J、P 与该系统都完整），所以数值与已发表的 B 略有差异。S1 不改尺寸，所以 raw 与 S1 的 B 相同。B < 0 表示物体偏小（代理普遍偏小）；偏小的物体更容易通过碰撞与边界检查，所以每个接受率都要与 B 一起读。GT = 测试房间的真值布局本身（同一检查器与 downstream.accept），只作参考，B = 0。
