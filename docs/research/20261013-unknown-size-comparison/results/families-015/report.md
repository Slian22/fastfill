# 按房型族的结果（EXPLORATORY，事后分析，不属于预注册方案）

OptiScene 论文只覆盖 bedroom / living / kitchen / bathroom 四类房型（eval_data.PAPER_STRATA）；本测试集有 15 个房型族。“论文覆盖 = 否”的族论文没有评测；OptiScene 公开的 SFT 和 DPO2 训练提示只有这四类，DPO1（7,951 对）另有 Library（study_office）和 Hallway + Corridor（circulation）各 16 对（各约 0.2%）。房型族由原始 room_type 经 scene.norm_room_type 后的确定性规则得到（mapping.md 列出每个原始字符串及房间数；规则见 room_families.py）。none = 没有 room_type（真实扫描，房型未知）；other = 有名称但无法归类（other room、misc.、studio、apartment 等）；二者论文覆盖记为“—”，不计入 other_families（与 E3 相同）。

各族结果很大程度上反映房间来自哪个数据源（表 0）。已知局限：论文四族里也有 OptiScene 没见过的商业/办公变体，留在论文族里，因此也不在 E3 中（eval-data-v1 上约 411 间：酒店、宿舍和标准间 128，办公和公共卫生间 111，游戏、娱乐和休息室约 103，办公茶水间 69）。

系统：J（联合预测尺寸）、P（训练集尺寸先验 + 模型布局，交付模型）、GT（测试集真值布局本身）。模型阶段：selected。完整率、检查器成功、下游接受以范围内全部请求为分母；B（足迹 log 偏差，负 = 偏小）、尺寸 log MAE、OOR（两两 XY 重叠率，不是越界率）只在各系统自己的完整房间上平均。检查器成功 = 冻结几何检查器；下游接受 = downstream.accept（EmbodiedGen Path A 规则移植，每扇门都作为入口），都在原始输出上计算。

差值为前者减后者，房屋连通组自举（2,000 次，seed 42，按来源签名分层，与 geometry.paired_intervals 相同的设计和抽样），标量只在两者都完整的房间上配对。房屋组 k < 10 时不给区间；k < 30 标记 few clusters，房间 < 50 标记 small n（report_v2._design）。区间警告（如 singleton_source_signature_strata）见 contrasts.csv。各族之间不做多重比较校正；所有数字仅作描述。

截断规则（修订 005，达上限且无 EOS 记为失败）：J/P 被翻转的原完整房间 {'joint': 0, 'placement': 0}；agent 按行（行内带标志时）{'L-raw': None, 'L-harness': None, 'O1a-raw': 0, 'O1a-harness': 0, 'O1b-raw': 0, 'O1b-harness': 0, 'O2-raw': 0, 'O2-harness': 0, 'O3-raw': 0, 'O3-harness': 0, 'O4-raw': 0, 'O4-harness': 0, 'O6-raw': 0, 'O6-harness': 0, 'O7-raw': 0, 'O7-harness': 0}。
