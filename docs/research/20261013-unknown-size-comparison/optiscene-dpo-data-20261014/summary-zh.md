DPO1 的 HD rejected 不是论文所说的 “SFT 模型采样”。98.2% 的布局里所有物体共用同一个 y；99.6% 的实例位移超过 1 cm，中位 3.61 m；77.0% 的实例改了朝向。“h” 取值 −7.10~6.70，像坐标而不是高度。物体间距离与 chosen 一致的 pair 为 0/4,317。来源**不明**，y 与 h 互换只是假设；`no_bbf1` 的含义也不明。

| DPO2 噪声 | pairs（HD/3D） | 动几个物体 | 位移 | 方向 | 旋转 |
|---|---|---|---|---|---|
| 出界型 | 1,983 / 1,576 | 中位 4 / 3 个 | 0.30–0.40 m，近均匀（均值 0.349） | 从房间中心径向外推（98% 偏差在 5° 内），优先推贴边的物体 | 几乎没有 |

DPO2 的噪声不是高斯分布（excess kurtosis 2.29 / 1.39），还带一个表层线索：322 个 3D rejected 里出现了 >π 的角度，而 chosen 从来没有。

官方超参：README 用 lr 5e-6、10 epoch、Qwen2.5-7B、LoRA r32/α16，β 未传入，即 TRL 默认 0.1；论文写的是 5e-7、5 epoch、Qwen3-8B、r16/α32。checkpoint 每 100 步存一个，README 里的 `checkpoint-XXXX` 靠手选，没有给出规则。按代码阅读，README 的命令跑不起来：`--dataset_file` 没有注册，文件名也对不上（未实际运行）。

## 2. 与我们的关键差异

| 维度 | 官方发布 | 我们（amendment 008–010） |
|---|---|---|
| DPO1 负样本 | 极易区分的崩坏布局 | 模型自采样（T 0.85），合法且与正样本不同即可，**不要求几何更差** |
| 有梯度比例 | 54.4% | 100% |
| 负样本 / 正样本 | 约 4 个，互不相同 | 1 个 |
| DPO2 扰动 | 平移+旋转；无明显违规：3D 约 10–13%（因 proxy 而异），HD 1.5% | 只平移，100% 是已验证的违规 |
| 输出是否含尺寸 | 否 | J 含，P 不含 |
| 训练长度 / ckpt 选择 | 每 100 步存，手选 | 009：5,500 步，只留最后一步；010：每 epoch 存，用 600 房 dev 选 |
| 评测 | OOR / FID / GPT-4o / UR，没有完整率 | 完整率、几何成功率、尺寸误差 |

## 3. 如何解释我们的结果（机制均为假设）

- **官方超参下崩溃（009）**：我们的负样本是模型自己的高概率输出，其中可能不少几何本身就合格（`rejected_geometry_success` 在服务器上，未核实）。
  - 用 5e-6 训 10 epoch 去压低这些序列，到第 8 epoch loss≈0、reward acc 1.0。
  - 之后完整率 J 0.997→0.883、P 只剩 0.496；几何成功率 J 0.388→0.213、P 0.390→0.093。这符合 likelihood displacement。
  - J 的尺寸也在持续变小，footprint bias −0.083→−0.357。
  - 官方同样的超参看起来 “能用”，原因可能有三：负样本差得离谱；近一半 pair 没有梯度，等效 lr 减半；ckpt 可能手选了较早的一步。何况他们的指标测不到格式崩坏。
- **rpo-dpo1 小幅有效**：chosen NLL（α 1.0）加上只训 3 epoch，限制了漂移；P 臂没有尺寸通道。不过 test 只从 0.390 到 0.398，dev 从 0.408 到 0.470，部分提升可能来自 dev 选择噪声（不确定）。
- **DPO2 无效**：
  - 每个正样本只有 1 个负样本，违规单一且已验证，又只有平移，所以 margin 达到 13–15、loss≈0。
  - 同一对每个 epoch 都重复出现，模型学到的是捷径。DPO2 的起点又是已经崩坏或漂移的 DPO1。
  - 结果是 dev 完整率 J 0.000、P 0.050（009），P 的 e1-dpo2 为 0.428。
  - 官方 Table 6 中 DPO2 带来的 OOR 0.033→0.023 没有完整率数据佐证，用发布的数据也无法复现。

## 4. 对下一步 on-policy DPO 的启示（建议）

1. **好/坏样本**：每个 prompt 从当前策略采 n 个，用几何检查打分，检查项包括可解析且完整、OOR、出界、尺寸误差。
   - chosen 取通过检查的最好样本；没有合格样本就回退到 GT 并打标。
   - rejected 取同一 prompt 下明显更差的样本，分差须超过阈值；分差小或两边都合格的 pair 直接丢弃。
2. **对数**：官方约 2,000 房 × 4 ≈ 8k 对。建议 ≥2,000 房、每房 2–4 个**不同**的负样本，并去重；dev/test 房间不能出现在训练集里。
3. **超参**：β 从 0.1 起步。每轮 1 epoch、多轮 on-policy 迭代，替代同一批数据训 10 epoch；保留 chosen NLL（RPO）。若把 lr 降到 5e-7，要处理 009 记录的 BF16 合并抹掉更新的问题。J 臂可考虑让尺寸 token 不进 DPO loss（未验证）。
4. **过拟合防护**：密集存 ckpt，按 dev 完整率加几何成功率来选；监控 chosen logprob 和输出长度。chosen logprob 下降、reward acc 到 1.0 或 margin 暴涨，就立即停。
5. **同类叠放负样本**：官方数据里只有个例（两个 nightstand 在同一点），重叠型一般只把 1 个物体推到邻居上，同类叠放没有被单独统计（未量化）。
   - 优先使用 on-policy 自然产生的叠放样本。
   - 不够时再从 chosen 合成：只改坐标，数值格式和角度范围保持与 chosen 一致，避免出现 >π 角度这类捷径。
   - 合成样本的占比控制在少数。

其他数据缺陷：3D 有 8 对面积为 0；DPO2 的 HD 中 183 对输出物体与输入不符，8 对 uid 错位。
