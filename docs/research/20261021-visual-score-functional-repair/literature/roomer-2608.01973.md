# Roomer: Reflective Object-Grounded Model Editing and Repair for 3D Indoor Layout Synthesis
- Authors: Lingwei Dang, Ziyan Qiu, Jiajia Cheng, Shishuo Shang, Zhenhao Zhang, Yufei Zhu, Qingxin Xiao, Pan Liu, Shenghui Huang, Yun Hao, Juntong Li, Qingyao Wu. 2026. https://arxiv.org/abs/2608.01973
- Commit rule (single gate): a candidate edit is committed only if target resolved, no new hard violations, protected satisfied relations preserved, structural validity holds, and global residual violation decreases by >= eps_V. eps_V = 1e-6 (App. F). Protected set Z_keep = every currently satisfied relation whose mutable dependencies are disjoint from the edited target; must remain satisfied.
- "Practical" metric families (App. F, J, K): bedside ratio, dining clearance, living functional angle, door proxy, walkable connectivity. Thresholds: living functional angle pass if >= 135 deg (no sofa-coffee or coffee-TV distance threshold); dining table side clearance >= 0.60 m; bed-side clearance (usable clearance / bed width) >= 0.30; walkable connectivity 0.60 m passage (0.30 m obstacle dilation). relation_distance threshold: not given (unverified).
- Relevance: the model for our repair step: apply move, re-verify whole scene, reject if any previously satisfied relation breaks.
