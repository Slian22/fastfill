# R3L: Reasoning 3D Layouts from Relative Spatial Relations
- Authors: Zhifeng Gu, Yuqi Wang, Bing Wang. 2026 (ICML 2026). https://arxiv.org/abs/2605.06758

## Evaluation protocol
- 9 scene types x 3 scenes = 27 tasks, open-vocabulary instructions, up to 40 floor-standing Objaverse assets. Generator GPT-5; baselines LayoutGPT, Holodeck, LayoutVLM.
- Physical: %CR, %OR (collision / out-of-range rates, lower better). Semantic: Realism, Functionality, Instruction-following, each 1-10.
- Pairwise judge: Gemini 3 Flash. One composite image (App. G.4): Layout A LEFT column (top-down above, side view below), Layout B RIGHT column. Prompt: "You are an expert judge comparing two 3D scene layouts"; criteria Spatial Realism, Functionality, Instruction Following; "You MUST pick a winner"; JSON {"winner": "A"|"B"}. A/B side randomised each step; three judge results aggregated by majority vote.
- Win rates and Elo (R3L 1866 vs LayoutGPT 1597 with LLM judge; 1905 in the 150-participant human study).
- Human agreement, Kendall tau-b (Table 6): user-user Real 0.56 / Func 0.55 / Instr 0.53; user-LLM Real 0.52 / Func 0.50 / Instr 0.56.
- Collision: AABB overlap with positive length on both x and y. Relations are differentiable penalties, directional (left-of, right-of, in-front-of, behind-of), facing, angle, placement, around (Appendix F; specific thresholds not read - unverified).

## Relevance
Best template for our judge: composite image, randomised order, 3-vote majority, forced choice. Includes an instruction-following criterion we must drop (no description in our input).
