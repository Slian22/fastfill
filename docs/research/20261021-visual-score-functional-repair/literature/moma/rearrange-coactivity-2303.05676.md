# Rearrange Indoor Scenes for Human-Robot Co-Activity
- Authors: Weiqi Wang, Zihang Zhao, Ziyuan Jiao, Yixin Zhu, Song-Chun Zhu, Hangxin Liu. ICRA 2023 (per project page yzhu.io). https://arxiv.org/abs/2303.05676 (read via ar5iv); code github.com/Rayckey/scene_coactivity
- What: re-optimises an existing furniture layout (SUNCG) for a mobile manipulator while keeping human functional groups (SUNCG spatial + ConceptNet semantic co-occurrence, GMM-pruned graph). Objective min sum H_s + beta * sum I_i; adaptive simulated annealing, then CMA-ES refinement; hierarchical (within groups, then groups as rigid units); all pairs collision-free.
- Robot terms: accessibility = signed distance field f_R(q) = f_B(q) - r_b (circular base inflated by safety radius r_b); reachability = pseudo-interaction f_I rewarding base poses within max arm reach d_max that approach the object from its interaction side (e.g. a cabinet door facing a wall is penalised). Values of r_b, d_max, alpha, beta not given. Robots in ablation: Husky+UR5 (large), Dingo+UR3 (small).
- Results: about 14% more accessible space and about 30% more reachable objects on average (abstract; 154 test scenes, per-scene values only in a plot). Human study: 11 participants, 7 pairs, 1-5 scale; scenes 1-5 not significantly different, scenes 6-7 rated lower after rearrangement (p = 0.0029, 0.0023).
- Stated limits: if the robot exceeds a size threshold no layout fits; gains only partly transfer between robots; motion-cost term only qualitative; SUNCG no longer available.
- Relevance: the closest prior work to "repair a layout for MoMa executability" (base-pose-at-interaction-side + free space), but no visibility, no opening sweep, no heights, no door entry, and no task-level success evaluation.
