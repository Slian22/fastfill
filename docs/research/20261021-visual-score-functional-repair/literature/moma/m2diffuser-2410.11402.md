# M2Diffuser: Diffusion-based Trajectory Optimization for Mobile Manipulation in 3D Scenes
- Authors: Sixu Yan, Zeyu Zhang, Muzhi Han, Zaijin Wang, Qi Xie, Zhitian Li, Zhehan Li, Hangxin Liu, Xinggang Wang, Song-Chun Zhu. arXiv 15 Oct 2024. https://arxiv.org/abs/2410.11402 (journal venue: unverified)
- What: scene-conditioned diffusion over whole-body trajectories with energy/cost guidance at inference; training data from the VKC optimisation planner (horizon 50 steps).
- Robot: 10-DoF: Dingo omnidirectional base (3-DoF) + Kinova Gen3 (7-DoF) + Robotiq 2F-85. Dims not given.
- Scenes: generated by PhyScene; grasp 24 scenes (17 train / 7 held-out), placement 32 (24 / 8); real: PolyCam-scanned living room, VICON localisation.
- Success: grasp = object-to-EE transform changes < 2 cm and < 15 deg after lift; place = object stationary after 600 sim steps and bbox overlap with target > 0.5; goal-reaching = EE error < 4 cm and < 20 deg.
- Results (with optimisation): seen grasp 30.54% / place 22.89% / reach 30.49%; unseen 14.33 / 12.25 / 12.61. Baselines Mpinets, Mpiformer <= 5% seen.
- Scene-caused failures: collision rates of the optimised model ~20-44% across tasks (e.g. 20.29%, 43.60%); baselines fail by collisions/contacts. No unreachable/occlusion breakdown.
- Relevance: a learned-scene (PhyScene) MoMa benchmark where collision with furniture is the main failure -> generated layouts need whole-body clearance around targets, not just base clearance; place success uses bbox overlap > 0.5 (a usable receptacle-fit check).
- Tags: whole-body-wheeled-bimanual, scene-gen-for-robots, data-generation
