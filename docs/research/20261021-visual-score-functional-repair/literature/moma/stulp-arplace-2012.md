# Learning and Reasoning with Action-Related Places for Robust Mobile Manipulation
- Authors: Freek Stulp, Andreas Fedrizzi, Lorenz Moesenlechner, Michael Beetz. JAIR 43:1-42, 2012 (DOI 10.1613/jair.3451); arXiv 1401.4599. https://arxiv.org/abs/1401.4599 (abstract only read)
- What: ARPlace = set of base positions each with a learned probability that the manipulation action succeeds, accounting for robot and object pose uncertainty; updated online; used by a transformational planner.
- Numbers: none in the abstract (body not read; unverified).
- Relevance: origin of "base region with success probability" (later MoMa-Kitchen, N2M, FloAff); supports scoring a layout by the area of the free, high-probability base region rather than existence of one pose.
- Tags: base-placement
