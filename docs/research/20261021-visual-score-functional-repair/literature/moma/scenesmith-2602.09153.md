# SceneSmith: Agentic Generation of Simulation-Ready Indoor Scenes
- Authors: Nicholas Pfaff, Thomas Cohn, Sergey Zakharov, Rick Cory, Russ Tedrake (MIT, TRI). Feb 2026, ICML 2026. https://arxiv.org/abs/2602.09153 (HTML v1 read)
- What: hierarchical VLM agents (designer/critic/orchestrator) build room- and house-level scenes: layout -> furniture -> small objects; text-to-3D statics, articulated objects (cabinets, drawers, appliances, doors) retrieved from ArtVIP. 210 prompts (SceneEval-100, type diversity, density, themed, house-level).
- Scene stats (Table 1/2): 71.1 +- 13.0 objects/room (baselines 11.2-23.0); house 214.1 +- 60.9 (Holodeck 81.3). COL 1.2% (baselines 3.0-28.9%), mean residual penetration 3.8 mm; STB 95.6% in Drake (8.1-60.8%); OOB 0.2%. House-level 0.9% COL, 79.8% STB (Holodeck 3.8% / 17.9%).
- Navigation metrics (App. L.2): NAV = largest connected free-floor area / total free floor (2D occupancy, connected components); ACC = VLM names each object's functional sides, 2D occupancy checks they are unobstructed. SceneSmith NAV 97.6, ACC 83.4, lower than baselines "given our 3-6x higher object density". No agent radius or pass threshold stated for NAV/ACC.
- Agent tool check_reachability (App. D.3): robot = disk of configurable half-width h_r; erode floor and dilate each furniture OBB by h_r; walkable region must be one connected component; outputs #regions, reachability ratio (largest region / total walkable), blocking furniture IDs. Examples: humanoid ~20 cm; Rainbow RB-Y1 (60x69 cm base) "approximately 35cm clearance". Grid size not given.
- Other checks (qualitative, no numbers): furniture in "clearance zone in front of doors" flagged; open connections must leave "a robot-sized passage"; window clearance above sill height.
- Robot eval (Sec 3.5, App. K): KUKA LBR iiwa14 "mounted on a mobile base with a telescoping lift joint", model-based pick-and-place (VLM task parse, antipodal grasps, collision-constrained IK, RRT-Connect) in Drake. 4 tasks x 25 scenes: fruit->plate 3/25, coke can shelf->table 6/25, cup floor->sink 4/25, water bottle kitchen->coffee table (house) 3/25; total 16/100 (degraded variant 12/100). Success judged by a VLM evaluator agent on symbolic state + renders, 299/300 agreement with manual labels.
- Failure causes: no per-cause breakdown (reachability/grasp/planning/perception) reported.
- Relevance: closest analogue to our setting (generated rooms -> mobile manipulator pick/place). Gives an implementable connectivity check (disk erosion + OBB dilation, single component) and a 35 cm half-width example for a 60x69 cm base; shows dense generated rooms lower NAV/ACC and that low task success is not decomposed into scene vs policy causes (open gap).
