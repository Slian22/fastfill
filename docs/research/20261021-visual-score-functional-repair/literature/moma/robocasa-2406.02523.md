# RoboCasa: Large-Scale Simulation of Everyday Tasks for Generalist Robots
- Authors: Soroush Nasiriany, Abhiram Maddukuri, Lance Zhang, Adeet Parikh, Aaron Lo, Abhishek Joshi, Ajay Mandlekar, Yuke Zhu. arXiv 4 Jun 2024 (RSS 2024 venue unverified). https://arxiv.org/abs/2406.02523 ; code https://github.com/robocasa/robocasa
- What: MuJoCo/robosuite kitchens: 10 floor plans x 12 styles = 120 scenes, layouts "compiled from home design and architecture magazines" and modelled "according to standard size and spatial specifications" (one-wall to U-shaped with island). No counter height / aisle width numbers in the paper.
- Tasks: 25 atomic (pick-and-place 8, doors 4, drawers 2, knobs 2, levers 3, buttons 3, insertion 2, navigation 1) + 75 LLM-generated composite; 50 trials over 5 fixed scenes.
- Robot: Franka Panda on Omron mobile base (Omni-Frankie-like); real: Panda on DROID platform. Footprint/reach not given.
- Success thresholds (code, robocasa main, read 2026-10-21): door/drawer open = every joint normalised qpos >= 0.90, closed <= 0.005; NavigateKitchen = base xy within 0.20 m of target and cos(dyaw) >= 0.98; pick-place helpers: gripper_obj_far th = 0.25 m, in-receptacle = contact + horizontal centre distance < 0.7 x receptacle horizontal_radius, obj_inside_of bbox corners within fixture bounds +0.05 m.
- Base placement (code env_utils.compute_robot_base_placement_pose): target base = fixture reference point offset 0.20 m along the fixture's facing axis (extra 0.10 m for fridge/housing cabinet/stacks); no collision check there; set_robot_base tries 50 collision-free samples per round, widening x by 0.10 m and y by 0.05 m each round. Door tasks place the base beside the swing: e.g. ManipulateLowerDoor x = fixture.width/2 + 0.2, y = -0.1; OpenDishwasher X_OFS 0.275; fridge OFFSET (0, -0.30) or (-0.30, -0.30).
- Object placement regions: fixture.get_reset_regions default z_range = (0.45, 1.50) m (absolute height of the surface); objects must fit the region footprint/height or the region is skipped.
- Failure causes: object diversity, dexterity (insertion), stage transitions; generated data "jerky motions and collisions"; sim-to-real gaps incl. base placement. Human-50 28.8% vs Generated-3000 47.6%.
- Relevance: gives directly usable thresholds: surfaces for task objects between 0.45 and 1.50 m; a free standing strip ~0.20 m in front of each target fixture plus room for the robot body; door tasks need standing room offset to the hinge side of the swing.
- Tags: sim-benchmark, articulated-objects, data-generation, base-placement
