# MolmoSpaces: A Large-Scale Open Ecosystem for Robot Navigation and Manipulation
- Authors: Yejin Kim, Wilbert Pumacay, Omar Rayyan, Max Argus (co-first) + 22 others (26 total; Ai2, PI Ranjay Krishna). arXiv v2 19 Feb 2026 (also RSS 2026 proceedings p091, unverified). https://arxiv.org/abs/2602.11337
- What: 230k+ indoor scenes from AI2-THOR / ProcTHOR / Holodeck lineages: MSCrafted 120 hand-made rooms; MSProc 12k heuristic procedural houses (1-10 rooms); MSProcObja 110k (THOR + Objaverse objects); MSMultiType 110k LLM-procedural scenes extending Holodeck (546 room types, 101 scene types, 52k personas, extra "grid" placement constraint); MSTwin 1 real-kitchen twin. ~130k objects, 48k manipulable, 42M grasp annotations; MuJoCo, Isaac, ManiSkill.
- Validity checks (MuJoCo): settle ~20 s; remove objects still jittering; fixed-vs-free collision -> remove free object, free-vs-free -> remove smaller; lift test: upward force, objects that rise < 5 cm inside another object's site removed; articulation test: joint must move through >= 70% of range, else blocking free objects are removed; occupancy maps for collision-free robot start poses. Navmesh/agent radius/grid size not given.
- Pass rates (%; stability/lift/intersection/articulation): MSCrafted 100.0/97.5/98.3/99.1; MSProc 99.4/99.7/99.9/97.4; MSProcObja 98.4/98.7/99.1/93.7; MSMultiType 94.9/99.6/93.7/65.2 (text says lowest articulation 63%, inconsistent with table). Isaac stability 92.5-95.9%.
- Failure attribution: "Manual inspection confirms that most failures arise from scene layout rather than limitations of the simulation engine." MSMultiType's low articulation rate: large objects were placed to keep door-to-door navigation clear, leaving articulation paths blocked (navigation clearance and opening clearance compete). Grasp failures: confined spaces limiting vertical clearance.
- Robots: Franka FR3 (DROID setup) for tabletop; Rainbow RB-Y1 (holonomic, bimanual) for navigation and door opening.
- Tasks / success: Navigate-to (RB-Y1) start 4-20 m from target, success = target visible from head camera AND within 1.5 m; Pick lift >= 1 cm; Pick-and-place >= 50% of object weight supported by receptacle, receptacle moved <= 10 cm or 45 deg; PnP-next-to: receptacle starts 30-50 cm away, end within 5 cm surface-to-surface on same support, receptacle moved <= 5 cm or 45 deg; Open >= 15% open; Close <= 15%; Open-door (RB-Y1) >= 67% open. Navigate-to evaluated on 2,000 trajectories in 679 houses (RING > DualVLN; numbers only in a figure, unverified).
- Sensitivity: wrist-camera occlusion drops pi0.5 to 2%, third-person occlusion to 20%; sim-real pick correlation Pearson R = 0.96, Spearman 0.98 (752 RoboArena tasks).
- Relevance: the closest published "procedural houses for MoMa" pipeline; gives concrete success definitions (visible + 1.5 m; door 67%) and a post-hoc validity filter (articulation >= 70% range) that we can mirror as symbolic opening-clearance checks; shows nav clearance vs articulation clearance trade-off is real in LLM-generated layouts.
