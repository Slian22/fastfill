# N2M2: Learning Navigation for Arbitrary Mobile Manipulation Motions in Unseen and Dynamic Environments
- Authors: Daniel Honerkamp, Tim Welschehold, Abhinav Valada (Univ. Freiburg). IEEE T-RO 2023 (DOI 10.1109/TRO.2023.3284346); arXiv 2206.08737. https://arxiv.org/html/2206.08737v2
- What: end-effector motion generator in task space + RL base (and torso) policy that keeps the arm kinematically feasible while avoiding obstacles from a local 3 m occupancy map.
- Robots: PR2 (omni base, base diagonal 0.91 m), Toyota HSR (omni), TIAGo (differential drive); max base 0.2 m/s, 1.0 rad/s. Goal height ranges used: PR2 [0.2, 1.55] m, TIAGo [0.2, 1.5] m, HSR [0.2, 1.4] m. LiDAR FOV 270 / 240 / 220 deg.
- Feasibility/success: IK via BioIK; success = within 2.5 cm and 0.05 rotational distance of the goal with no base or self collision; fail if deviation > 10 cm or 0.05 for > 20 steps.
- Layout parameters: training goals rejected if no path exists with 0.4 m inflation radius; goal distance 0.5-5 m; bookstore map passages "as narrow as 0.85 m"; door frame 0.89 m (narrower than the PR2 0.91 m diagonal); real HSR door frame 0.83 m.
- Results (analytical env., avg success): PR2 88.2% (MPC 57.3, E2E 0.0); HSR 82.4% (67.1, 28.1); TIAGo 65.4% (46.3, 0.0). Narrow bookstore is the hardest task: PR2 70.0, HSR 68.0, TIAGo 42.0; door: 98.4 / 88.0 / 62.4. Gazebo: PR2 79.2, HSR 82.7, TIAGo 62.8.
- Real world (Table VII): PR2 124/150 (82.6%): base coll 4, arm coll 5, grasp fail 9, IK fail 8; HSR 110/140 (78.6%): 3, 2, 9, 15, safety stop 1.
- Relevance: gives concrete reachable-height bands per robot (0.2 to 1.4-1.55 m) and shows passages ~0.85 m are the failure regime for a differential-drive TIAGo (42.0%); real failures are mostly IK/grasp, not base collision.
