# Habitat Synthetic Scenes Dataset (HSSD-200): An Analysis of 3D Scene Scale and Realism Tradeoffs for ObjectGoal Navigation
- Authors: Mukul Khanna, Yongsen Mao, Hanxiao Jiang, Sanjay Haresh, Brennan Shacklett, Dhruv Batra, Alexander Clegg, Eric Undersander, Angel X. Chang, Manolis Savva. 2023 (arXiv v3 8 Dec 2023). https://arxiv.org/abs/2306.11290
- What: 211 artist-made houses (Floorplanner; "predominantly re-creations of real houses by realtors"), 18,656 object models, 466 categories, 53.2K m2 navigable (252.2 m2 per scene), 329.7 instances / 61.5 categories per scene; scene set for HomeRobot OVMM and Habitat 3.0.
- Task/agent: ObjectNav (6 goal categories); LoCoBot, base radius 0.18 m, height 0.88 m; step 0.25 m, turn 30 deg; success = STOP within 0.1 m of a goal viewpoint.
- Viewpoint / navigability rules: reject viewpoints with no navigable position below, > 1 m from the object bbox, or outdoors; remove viewpoints snapped to navigable islands with radius < 1.5 m (tabletops, counters, beds); reject frame coverage < 0.1%; start 1-30 m geodesic from goal, near-straight episodes (geodesic/Euclid < 1.05) partly rejected.
- Findings: scale benefits "quickly saturate"; HSSD-122 zero-shot HM3DSem 19.15 SR / 7.71 SPL vs ProcTHOR-10K 12.53 / 5.26; ProcTHOR layouts have "a high peak and narrow distribution" of navigable area, HSSD has "more realistic architectural layouts" (corridors, non-rectilinear walls). 3D-FRONT rejected: sparse (empty kitchens/bathrooms/closets) and interpenetrating objects. Clutter metric HSSD 5.9 vs ProcTHOR 5.2.
- Relevance: same 1 m / 0.1%-coverage viewpoint spec as OVMM; "small islands" filter (< 1.5 m radius) is how they drop spurious navmesh on furniture tops; realism of layouts (not scale) drives transfer.
