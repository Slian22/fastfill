# N2M: Bridging Navigation and Manipulation by Learning Pose Preference from Rollout
- Authors: Kaixin Chai, Hyunjun Lee, Joseph J. Lim (KAIST). ICML 2026 (PMLR 306, pp. 12363-12382, per search); arXiv 2509.18671. https://arxiv.org/html/2509.18671
- What: after navigation, predict from one RGB-D view a distribution over base poses from which a given pretrained manipulation policy succeeds; labels from policy rollouts.
- Robots: sim Franka Panda on Omron base (RoboCasa); real Rainbow RB-Y1 (height-adjustable torso).
- Sampling: rollout labels in a 0.4 x 0.4 m square around the reference pose, +-15 deg; reachability baseline samples a 1 x 1 m square intersected with a 1 m circle around the object, +-30 deg (real: 0.5 x 0.5 m region ~0.5 m from object, +-60 deg); inference area 2 x 2 m with the object required visible.
- Results (Table 1, sim; task per fetch = CloseDrawer, unverified): Oracle 0.93 / 0.97 (DP / BC policy); Reachability 0.16 / 0.15; Mobi-pi 0.24 / 0.09; N2M 0.55 / 0.56. Real numbers only in figures.
- Failure notes: small objects, long distances, narrow preferred-pose regions.
- Relevance: a geometrically reachable base pose is far from sufficient for learned policies (0.16 vs oracle 0.93); the good region is about 0.4 m wide -> layouts should leave a base region of that size free in front of each task receptacle, not a single feasible point.
