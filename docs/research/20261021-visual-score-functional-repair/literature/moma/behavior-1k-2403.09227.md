# BEHAVIOR-1K: A Human-Centered, Embodied AI Benchmark with 1,000 Everyday Activities and Realistic Simulation (OmniGibson)
- Authors: Chengshu Li, Ruohan Zhang, Josiah Wong, Cem Gokmen, Sanjana Srivastava, Roberto Martin-Martin, ... Jiajun Wu, Li Fei-Fei (36 authors). arXiv 14 Mar 2024 (earlier CoRL 2022 version, unverified here). https://arxiv.org/abs/2403.09227 ; code https://github.com/StanfordVL/BEHAVIOR-1K
- What: 1,000 BDDL-defined activities in 50 scenes ("9,000+ object instances across 1,900+ categories"), simulated in OmniGibson (Isaac Sim). Scene sizes vary widely: Rs_int 72 objects / 5 rooms, house_single_floor 1375 objects / 23 rooms (Table A.4).
- Task family: rearrangement, cleaning, cooking etc.; primitives navigate, pick, place, push (push-open), dip, wipe.
- Success: BDDL goal predicates on physical state. OnTopOf = o2 in negative vertical axis of o1 + contact; InsideOf = axis-intersection test; "A joint is considered open if its joint state q is 5% over the lower limit".
- Robot: real Tiago++ (omni base, two 7-DoF arms, 1-DoF prismatic torso); footprint not in this paper (TidyBot++ Table 1 lists Tiago 54x54 cm, see tidybot-pp-2412.10447.md).
- Results: sim RL-Prim.Hist. 0.55 / 0.63 / 0.88 success (StoreDecoration / CollectTrash / CleanTable); real CollectTrash ~40% sim vs ~22% real optimal vs 0% real trained.
- Failure causes: sim "majority ... due to the visual policy (perception)"; real grasping "around 40% of the failures"; "44% of the errors come from the visual policy selecting the wrong action primitive"; "unfavorable robot base placement" from navigation inaccuracy (no count).
- Base-pose sampler in OmniGibson starter primitives (code, starter_semantic_action_primitives.py, main branch read 2026-10-21): BASE_POSE_SAMPLING_LOWER_BOUND = 0.0, UPPER_BOUND = 1.5 (m from object), yaw uniform in [-pi, pi], MAX_ATTEMPTS_FOR_SAMPLING_POSE_NEAR_OBJECT = 200, pose must lie in a room containing the object (20 tries), then cuRobo collision check + IK reach check; no visibility check in the sampler. Other: MAX_PLANNING_ATTEMPTS = 100, PREDICATE_SAMPLING_Z_OFFSET = 0.02, DEFAULT_COLLISION_ACTIVATION_DISTANCE = 0.02.
- Relevance: concrete, reusable base-placement feasibility rule: exists a collision-free base pose within 1.5 m of the target, in the same room, with IK reach. Room-membership requirement matters for open-plan layouts.
