# Automated Creation of Digital Cousins for Robust Policy Learning (ACDC)
- Authors: Tianyuan Dai, Josiah Wong, Yunfan Jiang + 5 others (8 total; Stanford). arXiv 2410.07408 (Oct 2024; CoRL 2024 per listings, unverified). https://arxiv.org/abs/2410.07408
- What: from one RGB image, builds sim scenes of "cousin" assets (GPT-4 captions, Grounded-SAM-v2 masks, Depth-Anything-v2 depth, CLIP category then DINOv2 candidate matching), places bbox centres at object centroids, fits floor/wall planes, infers "on top" with a 70% projected-polygon overlap threshold, de-penetrates vertically and resolves collisions in x-y.
- Tasks: sim Door Opening, Drawer Opening, Putting Away Bowl; real IKEA cabinet door + in-the-wild kitchen cabinet. Robot not named in the text read (unverified).
- Results (door opening, sim 50 / real 20 trials): Twin 100%/25%; Twin+DR 70%/55%; Twin+Cousin 92%/95%; Cousin 94%/90%.
- Scene-construction failure cases listed: high-frequency depth, occlusion, semantic category discrepancies, missing assets, relations other than "on top".
- Relevance: layout diversity around articulated fixtures beats an exact twin for zero-shot transfer; placement is bbox + overlap-threshold based, i.e. the same symbolic representation we use.
- Tags: real2sim/digital-twin, scene-gen-for-robots, articulated-objects, RL-sim2real
